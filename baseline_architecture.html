Why so simple?
This is the control condition in a controlled experiment.
Simplicity is deliberate — any added capability biases the comparison.
Variation must come from architecture, not prompting.
What gets measured
Every session logs: participant ID, task, response, model, temperature, duration.
Feeds into vulnerability density scoring and security reasoning analysis using scipy.
